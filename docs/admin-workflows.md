# 后台管理

后台按操作职责分组，账号说明不占用工作区域。

| 导航分组 | 功能 |
| --- | --- |
| 课程数据 | 按学期查询、维护开课记录，导入学期数据 |
| 内容运营 | 公告管理；关于、常见问题、友链等内容页面 |
| 站点配置 | 运营规则、常用页面文案、主题外观 |
| 开发维护 | 接口密钥与操作记录 |

「课程数据」和「开发维护」默认仅超级管理员可见、可操作。超管可在「用户管理 → 用户身份与权限 → 额外管理权限」分别下放这两类权限。资料站继承的管理员也需要下放权限；未授权时，直接访问相关页面或接口同样不可用。

## 内容页面

进入「内容运营 → 内容页面」，点击「编辑整页」即可维护关于和常见问题。新增友链时点击「新增页面」，填写标题「友链」、地址 `links`，在正文中用 Markdown 编写标题、列表和链接。

点击「预览」检查效果，勾选「发布页面」后保存，用户可通过 `/p/links` 访问。勾选「在页脚显示入口」会同时加入页脚导航。取消发布后保留内容为草稿，公开接口和页脚不再显示；不必删除内容。页面最多 30 个，单页内容最多 32000 字。

`{site_name}` 会替换为当前站点名称。原始 HTML 和脚本不执行。草稿仅在管理员设置中返回，公开页面接口只提供已发布内容。页面保存复用已有系统设置持久化与审计链路。

## 常用文案

「站点配置 → 页面文案」按全站、登录页、热度榜和通知邮件分组，并说明实际影响位置。站点名称位于全站分组首位，保存后自动刷新，更新导航、页脚、页面标题及安装名称。普通控件和状态文字保持固定。页面正文在内容页面中整页修改，不在这里拆成句子。

## 验证记录

已验证后台分层、整页修改关于、新增已发布友链、草稿不出现在公开接口、站点名称保存并在浏览器导航及页面标题生效。测试内容与名称随后恢复原值。后台仍使用频道账号身份授权，普通用户不能修改内容和设置。

## 主题外观

进入「站点配置 → 主题外观」，分别编辑浅色、深色模式的主题色、页面和卡片背景、文字、边框、评分与提示颜色。预览只影响编辑区，保存后当前页面立即应用，其他已打开的页面刷新后更新。更多颜色包含按钮、浮层、图表和侧栏。

「恢复默认颜色」先填回内置颜色，点击「保存主题」才会生效。十六进制色值支持六位颜色和八位含透明度颜色。安装应用的主题色、背景色同步使用浅色主题配置。

技术管理员：主题存入现有设置 `theme.palette`，公开接口 `/api/site-theme` 只返回经过验证的颜色。默认主题以 `frontend/src/config/theme-defaults.json` 为来源，由文案维护脚本同步 Go 内嵌副本。所有颜色字段必须完整，不能输入任意 CSS。

## 开课记录

在「课程数据 → 开课记录」选择学期后，可在每个表头下分别搜索课程代码、课程名称、主讲教师、开课单位，并按教学班数量范围筛选。顶部可查询完整课程序号；多项条件同时满足才会出现在结果中，名称、单位、主讲教师和课程序号需属于同一教学班。主讲教师和开课单位列展示所有教学班的相关信息，避免匹配结果藏在未显示的教学班中。

点击表头切换升序、降序；名称、教师与单位按第一教学班信息排序，数量按全部教学班数量排序。可调整每页 20、50、100 条，筛选和排序均查询整个学期，改变条件后回到第一页。「清除筛选」保留当前学期。新增、编辑和删除功能仍可使用。

已移除 ZIP 上传入口和 `/api/admin/course/import` 接口。教务同步仍在内部使用同一完整性校验与学期保存流程，已有点评保留。

## 教务同步

教务同步与开课记录合并在同一页面，默认折叠。收起同步区域不会取消任务；再次展开可查看二维码和进度。每保存一个学期会自动刷新课程与学期列表。

进入「课程数据 → 开课记录」，展开「从教务同步课程」，点击「扫码连接教务」，使用已绑定学校统一登录的微信扫码并在手机上确认。登录成功后会列出教务系统提供的学期，默认全选；可取消不需要的学期，再点击「自动同步」。同步逐学期执行，界面显示当前学期和已经保存的课程、教学班数量。

同步替换对应学期的开课记录，保留课程点评。采集结果必须完整并通过原有课程导入校验才会写入；失败后停止后续学期，已保存学期保留。取消不会撤回已经完成的学期。二维码过期、微信未绑定或登录失效时，按页面提示重新连接。

同步进度按当前学期显示「读取课程列表 → 获取课程详情 → 检查数据完整性 → 校验并保存」。列表阶段显示已读取教学班数、总数和分页进度；详情阶段显示成功读取数、读取失败数、重试次数及当前阶段百分比。上方的已保存学期数只在数据库保存成功后增加，详情读取完成不代表学期已经导入。总数尚未确定和校验保存期间不显示猜测的百分比。

进度每两秒刷新，并显示已用时和最后一次更新距今时间。超过三十秒没有新的采集进度时，提示正在等待教务响应，可继续等待或取消，不把等待直接判断为失败。刷新页面可继续查看同一任务。新版本进度需重新启动 API 后用于新建的同步任务；更新时先让正在运行的同步完成，避免中断本学期采集。

同一服务一次只运行一个连接/同步任务，由发起管理员查看和取消；刷新当前浏览器页面仍可查看任务。关闭页面不取消任务，重新部署或重启服务会结束连接，届时重新扫码。连接最长二十四小时，二维码等待最长三分钟，不长期保存登录会话或学工号密码。

### 技术管理员配置

API 镜像内置 Go HTTP 教务采集器，无需宿主机 SDK、采集器目录、Node 或浏览器。当前任务状态和临时 Cookie 保存在 API 进程内；开课计划列表和详情另有 24 小时磁盘缓存，重启后重新扫码可继续未完成采集。Docker 部署需保留 course_cache 卷。多副本需将该入口固定到一个实例。管理员不上传 ZIP，学期数据统一从教务同步获取。

镜像默认启用教务同步；设置 `JCOURSE_COURSE_SOURCE_ENABLED=false` 可关闭。采集器在 API 内运行，不开启额外端口、不写学校凭据或临时课表文件。扫码确认后先完成 CAS 回调、自动提交登录表单和业务会话验证，再读取全部学期目录。管理员与个人导入共用队列，个人默认并发 64，管理员全校同步独占运行，结束、取消或超时后释放本次连接。

详见 [Go HTTP 采集器](http-course-collector.md) 和 [资源预算](resource-budget.md)。旧浏览器版本的实际扫码结果不视为 Go 版本验证；新版本无人值守验证覆盖模拟 CAS/EAMS 完整链路，真实扫码后的业务采集需另行验证。

如果部署主机缺少所需运行环境、网络不可达，且修复需要修改操作系统或网络配置，按本任务范围记录为阻塞，不修改系统配置。

## 导入设置

超级管理员在「运营规则 → 导入设置」中设置个人扫码导入并发数（1～64）、个人教务扫码与手动添加开关、管理员教务同步开关，以及 MyCHU 预留入口是否显示。被授予站点设置权限的管理员不能修改这些设置。设置保存到数据库，重启后保持；增加并发立即接纳排队任务，降低并发等待已有任务结束。禁用不终止已提交任务，手动添加禁用不影响已有记录的编辑和删除。MyCHU 开关不会启用尚未实现的导入功能。

## 个人课程导入范围

个人教务扫码导入默认勾选教务目录最新学年及之前四个学年，春季、夏季学期均包含在内。用户可逐学期调整，或选择「全部学期」补录更早课程；只对勾选学期发起个人课表查询，不通过连续空学期推断就读范围。这里的五年是默认导入范围，不是对用户实际入学年份的识别。管理员全校开课记录同步不受影响。
