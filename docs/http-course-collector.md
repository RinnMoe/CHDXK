# 内嵌 Go 教务采集器

`backend/internal/infrastructure/bkjw` 在 Go API 内完成 CAS 微信扫码、扫码轮询、CAS 回调、自动提交登录表单、EAMS 业务会话验证、学期目录、开课计划分页与详情、个人课表读取。无需安装 Node、Playwright、Chromium 或外部 SDK；仅需容器能够访问学校统一认证、本科教务和微信扫码服务。

通过 `course_source.enabled` / `JCOURSE_COURSE_SOURCE_ENABLED` 启用，默认开启。旧的 node、runner、browser_path 配置已移除。不要把旧采集器挂载到镜像中。

学校登录态仅保存在当前任务独立的 Cookie jar；完成、取消、失败或超时后关闭 HTTP 连接并释放 Cookie，不写凭据文件，下次重新扫码。CAS 表单、跳转地址仅允许已知学校与微信服务，不执行上游 JavaScript；课表中仅解析 TaskActivity 的课程 ID 与名称字符串。课程 ID 用于内部教学班匹配，不显示给用户。

学期目录读取 EAMS `dataQuery.action` 的完整 semesterCalendar 数据，不从当前学年的可见下拉框猜测。个人查询只使用 std 分支的 ids，逐学期发起请求、去重教学班，合法空课表返回空列表；陌生错误页面、解析异常、未登录或无权限不会当成空课表。暂时性网络故障、HTTP 500/503 和限流会持续退避重试，单次操作最多尝试 50 次或约 20 分钟；等待间隔从 2 秒增加至最多 60 秒，单次 HTTP 请求超时为 90 秒。明确登录失效或无权限确认 3 次后停止，页面结构与课表解析异常最多尝试 8 次。取消任务会立即打断重试等待。

开课计划逐页校验页码、总数、表头和重复课节，逐条读取详情并校验学期与课程代码；登录回跳、学期目录、列表和详情共用节流器，上一个教务响应完成后初始等待 600 毫秒，连续成功后逐步降至 150 毫秒（另受全局请求预算约束）才发起下一请求，教务返回 HTTP 429 或“请不要过快点击”等频率限制提示时自动降速，重试同样受节流限制，最后沿用现有完整学期导入校验和事务。当前单响应最多 16 MiB、学期最多 20000 条课节、完整文档和报告最多 32 MiB；个人单学期最多 1000 个去重教学班。超限或采集不完整不会提交该学期。

自动测试：

```bash
cd backend
go test -race -tags test ./internal/infrastructure/bkjw ./internal/application
# 可选真实二维码获取测试，不需要手机确认，不打印二维码或登录凭据
BKJW_LIVE_QR=1 go test -tags test ./internal/infrastructure/bkjw -run TestLiveQRCode -v
```

本轮无人值守验证：模拟 CAS/EAMS 完整流程、真实二维码获取、Linux API Docker 构建。真实扫码后的学校全学期采集尚未验收；旧浏览器版本的成功记录不替代新版本验证。公网域名与资料站登录配置不受本次采集器迁移影响。

## 并发与内存

默认支持 8 个个人导入同时运行，设置允许上限为 64，队列总容量 128；管理员全校课程同步独占运行。超级管理员可在后台「运营规则 → 导入设置」中调整并发（1～64）及各导入方式开关，保存后无需重启。五容器内存额度合计 512 MiB，详见 [资源预算与压测记录](resource-budget.md)。临时结果保留准确统计及每学期前 20 条未匹配明细，任务历史最多 128 个用户，不影响已保存的选课记录。

容量测试可在隔离的 Linux API 容器中运行编译好的 Go 测试程序：`BKJW_LOAD_CONCURRENCY=64` 启用模拟采集；额外设置 `BKJW_LOAD_DB=1` 则用容器中的 `JCOURSE_POSTGRES_DSN` 创建并清理独立 schema，验证实际匹配与写入。禁止将容量测试指向生产数据库；测试不访问学校服务。

## 断点恢复

管理员开课计划按列表页、教学班详情保存到磁盘缓存。重新扫码并选择相同学期，会复用 24 小时内的缓存，只获取未完成的数据；学校登录态不写入缓存。进程重启后可读取原任务进度与学期选择；认证连接需重新扫码，课程缓存保留。完整学期校验通过后才执行数据库事务，不把未完成的采集覆盖到开课记录。

如需获取教务新变更，勾选「重新采集所选学期（不使用已有缓存）」。进度显示缓存恢复数量、重试次数与等待倒计时。部署时为 API 挂载 course_cache 卷至 /app/.local/course-cache，或通过 course_source.cache_dir 指定可写目录。首次部署此功能前已经丢失的内存进度无法恢复。

## 教师资料与个人课表

教师批量同步和单人自动填写共用教师主页 HTTP 采集器：成功验证的目录页、主页分别以原子文件写入缓存，24 小时内重复同步只补读未成功的页面。网络故障、HTTP 429/5xx 最多尝试 50 次或约 20 分钟，2～60 秒退避，单请求超时 90 秒；格式异常最多尝试 8 次，不缓存维护页和损坏结果。批量任务总时限 24 小时，显示缓存页面数、累计重试次数和等待重试的请求数。部分主页最终失败时仍保存成功资料，并保留失败项原有资料与手工覆盖；再次同步补采。勾选「重新采集全部教师资料」绕过缓存。

个人课表按学期缓存成功解析的课程，路径用登录后取得的学校身份与学期计算散列，不保存学校身份明文、Cookie 或二维码；重新扫码后先确认当前学校身份，不能复用另一学校账号的缓存。缓存使用期 24 小时，已完成学期导入仍按原事务保存、去重；任务总时限由 15 分钟放宽到 2 小时，沿用教务宽容重试。可勾选「重新读取全部学期」跳过缓存。

三类缓存均位于 course_source.cache_dir，由 Docker 的 course_cache 卷保存；任务进度另外持久化到 jobs 子目录，不包含二维码、Cookie 或个人未匹配课程名称；重启后显示恢复提示，重新扫码并确认学期后复用成功数据。个人课程缓存与公开开课记录、教师主页分别存放，不影响 ResHub 登录和积分调用。

教师目录按学校页面脚本的 letter 升序查询。分页推进校验同时用于缓存读取和 HTTP 响应：若某页全部为已出现的主页，自动丢弃该页缓存并按暂时性故障退避重读，不将重复页写入新缓存；其他目录页和教师详情缓存保留。

## 本地可靠性优化（2026-10-13）

全校与个人教务查询共享进程级请求预算：初始请求间隔 500 毫秒、最多 3 个在途请求，连续成功后最低 250 毫秒；单连接仍串行且独立保存 Cookie。收到限流或明确维护页时整体降速，最长间隔 10 秒；429/503 尊重 Retry-After（最多等待 20 分钟），重试增加随机退避。接口永久拒绝不会继续反复重试。已有 CAS 会话可恢复教务会话时，原查询自动重放；真正登录失效仍须扫码。

课表解析定位脚本中的数据构造器，兼容空白、注释和 window 前缀，忽略字符串与注释中的示例；只解码课程标识、名称字面量、字符串拼接与此前的字符串变量赋值，不执行脚本或函数调用。连续两次收到相同的不可解析响应时及时停止，保留解析错误码。未知、损坏或登录响应不能作为空课表。学期读取失败时重新获取入口，避免持续解析同一份错误页面。

全校课程详情首轮每条最多尝试 3 次，单条临时或格式失败记录后继续其余课程，再集中补采失败项。认证、权限、取消和缓存保存错误立即停止。全部详情通过校验后才生成完整导入结果；失败学期不会覆盖数据库，已完成详情在磁盘缓存中保留。

任务进度最多每秒保存一次，状态变化和学期保存立即写入；个人报告只持久化统计，不保存未匹配详情。记录有效期 72 小时，数据缓存仍为 24 小时。重新扫码保留原学期选择，但不会依据旧任务结果跳过个人学期，以免扫码账号改变时复用错误结果。恢复保存失败会在页面显示警告。默认并发从 64 降为 8；已经保存过的管理员并发设置保留。

验收需在相同网络出口、账号和学期下观察真实扫码后的耗时、重试次数、恢复数量与最终结果。模拟测试和二维码获取检查不能证明真实完整导入成功率。

### 本机验收入口

本地验收工具位于 `backend/.local/collector-preview/`（忽略目录，仅供本机测试），运行 `pwsh -File backend/.local/collector-preview/start.ps1` 后打开 `http://127.0.0.1:5187/`。支持真实个人扫码、全校开课读取与教师公开目录读取；只验证采集，不写网站数据库。默认选最新学期，可勾选更多；首次实测建议勾选“不使用缓存”，再对比续采。教师验收入口只读取目录，不拉取全部主页详情。

2026-10-13 本机启用 Windows 系统代理，学校域名解析到 198.18.0.0/15 虚拟地址；Go 未配置代理时初始登录请求失败，设置 HTTP_PROXY/HTTPS_PROXY 到同一本机代理后真实二维码约 1.4 秒获取成功。启动脚本只在检测到启用的回环代理时给子进程设置代理，不改变系统配置。正式 API 在此 Windows 网络环境下也应设置这两个环境变量；生产服务器应依据自身网络配置，不能直接复制本机代理地址。该结果仅证明二维码准备阶段，不证明扫码后的完整采集。

本地只读调试工具可显式保留内存登录态，查询完成或失败后可再次选择学期，最长 30 分钟；主动断开、进程重启或学校会话失效后需重新登录。正式导入任务仍在结束时释放会话。2026-10-13 真实扫码后读取 2026-2027-1 学期成功，返回 10 门课程，零重试；这证明个人查询链路可用，尚不能证明全目录吞吐或长期稳定性。
