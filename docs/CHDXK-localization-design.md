# 频道课程榜：长安大学专用架构

频道课程榜服务长安大学，本站独立维护账号、密码和管理权限，res-hub 提供主要授权登录与积分。本项目尚未上线，已移除其他学校旧 v1 账号、积分迁移工具，课程通过内嵌教务扫码采集和后台维护。

## 数据归属

| 数据 | 唯一来源 | 本站职责 |
| --- | --- | --- |
| 本站账号、密码、权限与处罚 | CHDXK | 独立登录、资料站身份绑定、管理员继承与分项授权 |
| 积分 | res-hub | 查询余额流水；点评奖励持久化、幂等重试与冲正 |
| 课程和教学班 | 本科教务系统 bkjw.chd.edu.cn | 内嵌扫码采集与学期导入；管理员维护 |
| 点评、投票、关注、管理备注 | 频道课程榜 | 评分、讨论热度和奖励共享同一课程身份 |
| 校园应用入口 | MyCHU | 复用结构化 API 和教务采集字段；不复制学校密码或 Cookie |

## 真实系统调研（2026-10-05，只读）

在用户已登录的 Codex 浏览器中查看了本科教务的课表、全校开课查询、教学任务详情，以及畅课课程列表和实际 JSON 查询响应。只记录接口路径与课程数据结构，不保存凭据、个人学号、成绩、作业或学习进度。

| 系统 | 已观察到的接口 | 结构 |
| --- | --- | --- |
| 本科教务 | `/eams/stdSyllabus.action` | 项目、学期选择 |
| 本科教务 | `/eams/stdSyllabus!search.action` | HTML 表格、分页；按课号、课程代码、名称、类别、教学班和教师查询 |
| 本科教务 | `/eams/stdSyllabus!info.action?lesson.id=…` | 教学任务详情：校区、院系、语言、考核、人数、周次、学时 |
| 本科教务 | `/eams/courseTableForStd!courseTable.action` | 私人课表、课程序号、课程代码及多教师；不作为全校课程全集 |
| 畅课 | `/api/my-courses` | courses 数组；page、page_size、pages、total 等分页字段 |

畅课课程响应包含 `id`、`course_code`、`name`、`academic_year`、`semester`、`department`、`instructors`。学年、学期、院系为带 id/name 的对象，教师为 id/name 数组。页面中新旧路径并存，课程列表页面使用 `/zh-Hans/course`，课程链接仍为 `/course/<id>/home/overview`。不应将新页面结构等同于旧 Angular 页面。

本科教务 `lesson.id`、畅课 `id` 和本站课程整数 ID 属于三个不同命名空间。观察样本中畅课 `course_code` 对应教务课程序号（如课程代码加教学班后缀），匹配时必须同时核对学年学期和完整课程序号，存在歧义时返回候选而不猜测。不能从名称猜课程、从教师姓名猜学校工号，也不能直接移植某个系统的学期数字 ID。

## 数据模型与查询

管理员教务同步使用内嵌采集器，扫码后逐学期获取开课计划，完整学期写入 PostgreSQL；用户个人课程导入也使用 CAS 扫码，逐学期匹配本站已有课程和教学班。两种导入均在任务完成或取消后关闭学校临时连接，不持久保存登录态。

来源只接受 `bkjw.chd.edu.cn`，来源课节 ID 保持原值。课程下有学期开课，学期开课下有教学班。教学班保留课程名称、类别、校区、院系、课号、教师、人数、学时、周次、考核、语言和大纲链接。重新导入只替换目标学期开课与教学班，课程和点评关联保持稳定。

教师内部标识以规范化姓名和开课单位生成，不能宣称为学校工号。同名同单位教师缺少额外来源标识时无法自动区分。查询涵盖所有教学班授课教师，包含共同授课者。课程的学期和校区筛选必须同时命中一个教学班，避免跨学期错误拼接条件。

MyCHU 可通过本站课程和教师 API 消费同一数据；其学校统一身份登录和教务 Cookie 留在学校服务边界。res-hub 登录不会自动赋予学校系统访问权限。私人课表匹配和畅课关联需要用户授权且使用准确的来源标识，个人课程已支持 CAS 扫码逐学期导入和手动选择本站已有教学班；MyCHU 导入只预留入口。

## 权限与受众

资料站登录按真实 `res_hub_role` 继承本站管理员，不依据资料站当前权限模式；资料站超管不自动成为本站超管。本站主动管理员身份、额外功能授权、封禁与禁言独立维护。登录会话保存选定账号和认证版本，多绑定时先选择本站账号。初始 ID=1 超管通过日志中的账密登录并强制首次改密。详见 [账号与权限说明](bootstrap-and-points.md)。

普通管理员管理课程、公告、点评和运营文案；技术管理员处理部署、OIDC 客户端、系统 API Key、迁移与故障排查。普通用户提示围绕课程、点评和登录结果，避免令牌、内部数据库和协议错误等技术细节。

## 技术结构与验证边界

Go DDD/CQRS、React、PostgreSQL、Redis 和 Asynq 沿用现有实现；API 与 taskworker 必须同时运行。`jcourse` 模块名和 `JCOURSE_` 环境变量只是内部技术标识，不是多校适配机制。新增索引与结构通过四位顺序编号 up/down SQL 迁移，不改写历史 SQL。

上线接入见 [res-hub 上线指南](reshub-launch-guide.md)。本地测试与真实 HTTP 登录不等同生产 HTTPS/mTLS 或全校采集验证。系统环境修改超出任务范围时跳过并记录阻塞。
