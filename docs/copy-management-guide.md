# 页面文案维护

## 普通管理员

在频道以管理员身份登录课程榜，进入后台的「系统设置」，下方「页面文案」可以搜索当前页面的原文。按普通用户、普通管理员、技术管理员筛选，找到相应条目后修改并保存。刷新页面即可看到结果，不需要发布代码或重启服务。

「恢复默认值」先把默认内容填入编辑框，再点击「保存文案」确认。带有 `{v0}`、`{v1}` 的条目会自动填入数量、名称或日期；可以移动这些内容标记的位置，但不能删除或增加标记。保存失败时查看条目下方的提示。

站点名称可搜索「频道课程榜」。联系邮箱可搜索「联系邮箱」，留空时隐藏联系方式。安装应用的名称、说明及快捷入口文案也使用后台设置；已安装应用的显示名称何时更新由浏览器决定。

面向同学的文案应短且易懂，避免出现客户端、令牌、数据库等实现词语。后台维护说明应帮助普通管理员判断如何操作。配置标识以辅助文字显示，文案条目的来源路径点击标识后展开，供排查问题时查看。

课程名称、教师信息、点评内容、管理员备注和公告是业务内容，在各自管理页面维护。身份、权限、接口参数及筛选值不随文案变化；不要用改文案来代替业务规则设置。

## 技术管理员

文案定义在 `frontend/src/config/copy-catalog.json`，Go 内嵌副本在 `backend/pkg/sitecopy/catalog.json`。维护脚本通过语法树提取展示文案，稳定标识不依赖显示内容；移动组件不需要更换已有标识。

```powershell
cd frontend
node scripts/manage-copy.mjs --extract
node scripts/manage-copy.mjs --check
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

提取范围为实际产品代码；测试和演示数据、协议标识、数据哨兵、日期格式及业务比较条件不参与改写。新增展示文案后运行提取，检查生成的调用与使用对象。新增带有富文本或特殊模板的表达式时，应人工检查参数是否完整。

`GET /api/site-copy` 在登录前提供公开展示文本，不含私有业务设置。页面启动先载入文案，再加载应用模块，确保导航和模块级选项也使用配置；失败或超时会使用内置默认值。保存走已有管理员设置接口与审计日志。系统设置缓存按原有机制失效；浏览器刷新后加载新值。

错误响应在展示层应用配置，内部错误标识和授权判断保持稳定。PWA 从 `/api/site.webmanifest` 读取实时名称、说明和快捷入口文案，不需要为了修改名称重新构建前端。文案以 React 文本显示，不执行管理员输入的 HTML 或脚本。

## 验证记录

覆盖登录前获取、普通用户写入 403、管理员保存、动态标记缺失或增加时 400、私有设置未公开、请求间文案隔离、浏览器显示新名称和动态安装清单。恢复默认值和修改也进入原有设置审计记录。

异常点评提醒邮件的标题、字段和说明也在文案设置中维护。账号限制由频道处理，课程榜不会发送已经封禁账号的错误通知。
