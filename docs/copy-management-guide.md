# 页面文案维护

## 普通管理员

使用频道管理员账号登录课程榜，进入后台的「系统设置」，下方「页面文案」只提供 14 项常用运营文案。可按名称或内容搜索，修改并保存后刷新页面即可看到结果，不需要发布代码或重启服务。

可修改范围：站点名称、联系邮箱、应用简介、站点介绍、非官方说明、点评管理说明、登录与内容保存的隐私说明、个人信息保护提示、登录说明、热度榜介绍与规则，以及异常点评提醒邮件的标题和说明。

「加载中」「保存」「标题」等按钮、状态提示、字段名称、导航名称和常规错误提示使用固定文案，不在后台提供修改。课程名称、公告和点评内容仍在各自页面管理。

「恢复默认值」先把默认内容填入编辑框，再点击「保存文案」确认。保存失败时查看条目下方的提示。

站点名称可搜索「站点名称」。联系邮箱留空时隐藏联系方式。安装应用的名称和应用简介使用后台设置，快捷入口名称保持固定；已安装应用的显示名称何时更新由浏览器决定。

面向同学的文案应短且易懂，避免出现客户端、令牌、数据库等实现词语。后台维护说明应帮助普通管理员判断如何操作。配置标识以辅助文字显示，文案条目的来源路径点击标识后展开，供排查问题时查看。

课程名称、教师信息、点评内容、管理员备注和公告是业务内容，在各自管理页面维护。身份、权限、接口参数及筛选值不随文案变化；不要用改文案来代替业务规则设置。

## 技术管理员

默认文案目录在 `frontend/src/config/copy-catalog.json`，Go 内嵌副本在 `backend/pkg/sitecopy/catalog.json`。只有明确标记 `editable: true` 的条目注册为后台设置，并通过 `label` 提供易懂的设置名称；其他目录条目是固定默认值，忽略旧数据库值和客户端传入的覆盖值。维护脚本通过语法树提取默认文案，不会自动扩大可编辑范围。

```powershell
cd frontend
node scripts/manage-copy.mjs --extract
node scripts/manage-copy.mjs --check
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

提取范围为实际产品代码；测试和演示数据、协议标识、数据哨兵、日期格式及业务比较条件不参与改写。新增展示文案后运行提取，检查生成的调用。只有明确的运营需求才新增可编辑条目；通用控件和状态文字保持固定。

`GET /api/site-copy` 在登录前只提供 14 项可编辑文案，不含固定界面文字和私有业务设置。页面启动先载入文案，再加载应用模块；失败或超时会使用内置默认值。保存走已有管理员设置接口与审计日志。系统设置缓存按原有机制失效；浏览器刷新后加载新值。

错误响应使用固定提示，内部错误标识和授权判断保持稳定。PWA 从 `/api/site.webmanifest` 读取实时名称和应用简介，不需要为了修改名称重新构建前端。文案以 React 文本显示，不执行管理员输入的 HTML 或脚本。

## 验证记录

覆盖登录前获取、普通用户写入 403、管理员保存、固定文案不注册为设置且不能被覆盖、私有设置未公开、请求间文案隔离、浏览器显示新名称和动态安装清单。恢复默认值和修改也进入原有设置审计记录。

异常点评提醒邮件只提供标题和说明供管理员维护，邮件字段名称保持固定。账号限制由频道处理，课程榜不会发送已经封禁账号的错误通知。
