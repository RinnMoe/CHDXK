# 本站账号、管理员权限和资料站积分

## 初次启动（技术管理员）

初始化数据库并启动 API。首次启动创建 ID=1 的初始超级管理员，在 API 启动日志（Docker 部署时为 API 容器日志）输出 `username` 和 `password`。进入登录页，点击“使用本站账号登录”，使用日志中的账密登录。首次登录必须修改密码，完成前不能访问业务和管理接口。

密码使用 bcrypt 保存。普通重启不重置密码，也不会再次输出凭证。请在首次启动时保存初始凭证，并在首次登录后设置自己的密码。旧魔法链接入口及轮换参数已经移除。

## 日常登录与绑定（用户、管理员）

登录页默认提供“通过资料站登录”。若该资料站身份没有绑定本站账号，系统创建新的本站账号并绑定；已有一个绑定时直接登录；存在多个绑定时显示账号选择页。每个本站账号的课程、点评和处罚独立。

在个人菜单“设置”中可修改本站账号名与昵称、设置或修改本站密码、绑定或更换资料站账号。所有本站账号都可以绑定资料站，同一资料站身份可同时绑定多个本站账号。设置本站密码后才能解除绑定，避免失去登录方式。更换或解除绑定会使原本站会话失效；绑定操作完成后的当前会话继续有效。改密会使其他设备的本站登录会话失效。

资料站授权创建的账号没有默认本站密码，可在登录后的设置页自行设置。账密注册默认关闭；拥有“站点配置”权限的管理员可在“运营规则 → 账号 → 开放本站账号注册”启用。关闭后登录页不显示注册入口，服务器也拒绝注册，但仍允许资料站首次授权创建账号。

## 身份与授权（超级管理员）

| 身份 | 默认能力 |
| --- | --- |
| 初始超级管理员 | 所有本站管理能力，包括用户、权限、积分、站点配置和开发维护 |
| 管理员 | 内容维护、禁言与封禁用户，以及被授予的额外管理功能 |
| 用户 | 浏览、导入自己的课程、发布点评等普通功能 |

资料站管理员（包括资料站超管）在本站继承管理员身份，切换资料站的普通用户模式不影响此身份；只有本站初始账号是超级管理员。本站主动授予的管理员身份与资料站继承身份独立。取消本站主动授予的身份不会撤销资料站管理员继承的身份。

后台“用户管理”支持查询、创建账密账号、编辑资料、重置密码、删除本站账号、处理违规和调整积分。权限按钮可分项授权“用户增删改与密码重置”“用户身份与权限分配”“积分发放与收回”“站点配置”“开发维护与接口密钥”。有权限分配能力的管理员只能下放自己拥有的权限，不能授予超级管理员身份，也不能处理权限高于自己的管理员。

初始超级管理员与当前操作账号受保护，不能通过后台用户管理将其封禁、删除或降权。自己的资料与密码在个人设置中维护。管理员创建或重置密码的账号下次登录必须改密。

## 本站处罚

禁言阻止普通用户发布和编辑点评；封禁阻止登录与受保护接口访问。可指定结束时间或长期处理，并记录原因。解除处理与到期后恢复使用。处罚只写入 CHDXK，不调用资料站封禁接口。删除本站账号后不能登录，已发布点评保留，资料站账号不受影响。

## 积分

只有绑定资料站且资料站提供积分账户的本站账号可以使用积分。未绑定的账号（包括初始超管）可以正常使用其他本站功能，积分页提示绑定，发布点评不创建积分奖励。资料站配置文件管理员可能没有积分账户，这与本站管理权限无关。

同一资料站账号绑定的多个本站账号共用资料站余额。后台发放、收回会实际调整该资料站余额；填写原因后提交，服务端使用业务键防止重复发放，并记录操作日志。只拥有默认内容运维权限的管理员不能调整积分。

点评奖励仍使用现有运营规则与异步任务，删除点评撤回对应奖励。奖励保存发布时的资料站身份，更换绑定不会将旧奖励错误地撤回到新账号。请同时运行 `taskworker`，并为资料站客户端配置 `client_credentials`、`points.read`、`points.write`。
