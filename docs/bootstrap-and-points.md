# 初始管理员、频道账号和积分

## 初次启动（技术管理员）

先应用数据库迁移，设置 `bootstrap.public_url` 为课程榜前端地址，然后启动 API。首次启动会创建 ID 为 1 的“初始超级管理员”，并在启动日志输出魔法登录链接。打开完整链接即可进入后台，请妥善保存。

链接的凭证位于 URL 的 `#token=` 部分，页面通过请求正文完成验证后会清除地址栏中的凭证。数据库只保存凭证摘要。普通重启不会更换链接，也不会再次输出凭证。

丢失链接时，可由技术管理员运行 API 启动参数 `--rotate-bootstrap-link`，从新的启动日志取得替代链接。此操作会使旧链接失效；已有绑定不变。不要将实际链接写入文档或公开日志。

迁移 `0018` 为初始管理员保留 ID 1。如果此前 ID 1 已属于 SSO 用户，迁移会移动该用户及其关联数据到新的 ID，不会把该用户变成初始管理员。

## 绑定和日常登录（管理员）

1. 使用魔法链接登录初始管理员。
2. 打开个人菜单中的“设置”，点击“绑定频道账号”。
3. 在频道完成登录和授权。绑定以频道返回的账号身份为准，无需手工填写账号 ID。
4. 以后从频道登录时，如果同时关联了原有账号和初始管理员，会显示账号选择页面。

选择初始管理员后保留其超级管理员权限；选择原有账号后，权限跟随频道账号的真实角色。频道管理员即使切换到普通用户模式，在课程榜仍是管理员。

更换绑定也在“设置”完成。旧绑定的 SSO 登录将不能再选择初始管理员，已选择初始管理员的旧 SSO 会话也会失效；原有普通账号不受影响。原魔法链接仍然可用，可以在频道暂不可用时进行站点维护。

## 积分账户

| 登录账号 | 积分行为 |
| --- | --- |
| 未绑定的初始管理员 | 可以配置站点和管理内容；积分页提示绑定，发布点评不创建积分奖励 |
| 绑定到有积分账户的频道用户的初始管理员 | 使用该频道用户的积分账户，与原有账号共享余额 |
| 频道用户，包括用户库中的管理员 | 使用频道提供的积分账户 |
| 频道配置文件中的管理员 | 该类账号本身没有积分账户，积分页说明暂不可用 |

“管理员权限”和“是否有积分账户”是独立的属性。出现无积分账户并不表示登录失败，也不表示权限不足。

课程榜查询主站余额和本客户端的积分流水。点评奖励由现有运营规则控制，异步处理程序负责发放；管理员删除点评后撤回对应奖励。业务键保证重复处理不会重复发放，冲正保证重复撤回不会重复扣分。奖励保存发布时的频道账户身份，即使初始管理员更换绑定，旧奖励也会撤回到原账户。

发布和首评奖励可以同时启用，首评奖励只对课程的首次有效点评发放。后台将奖励分值设为 0 或关闭开关时不发放该奖励。请确保 `taskworker` 与 API 同时运行，且频道 OIDC 客户端允许 `client_credentials`、`points.read` 和 `points.write`。

课程榜目前提供积分查询、流水、点评奖励和撤回。积分转账等主站功能仍在频道完成。
