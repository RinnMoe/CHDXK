# 课程与教师热度榜

## 普通用户看到什么

热门页同时提供课程热度榜和教师热度榜，可切换本周、本月。点击课程或教师可继续查看详情和点评。热度表示讨论活跃程度，不是教学质量、满意度或官方评价；评分保持原有计算方式。

点评发布、点评更新和有用投票沿用现有热度任务、后台权重设置、周期划分和课程热度存储。教师榜不另建积分、投票或计数系统：汇总每位教师当前任教课程的热度，每门课程只算一次，合授教师各获得该课程的同一热度。课程的最新开课学期用于判断当前任教关系；只有没有任教记录时才使用课程主教师。同分先比较有互动的课程数量，再按教师编号稳定排序。

周和月按上海时区计算。本期无互动的教师不上榜。榜单最多查询 100 项，页面默认显示 50 项。导入教师关系变更后，教师榜直接查询当前关系，避免课程榜与教师榜缓存失配。

## 普通管理员怎么维护

维护准确的课程和任教信息；在系统设置调整现有点评与投票热度权重。不要把榜单宣传为教学质量排名。课程数量较多的教师更容易获得讨论热度，用户可从详情查看具体课程。

## 设计参考与技术验证

[IMDb MOVIEmeter](https://www.imdb.com/chart/moviemeter/)将流行度榜与评分区分。本项目采用同样的概念区分，但只使用项目已有的真实点评互动，不收集额外浏览行为。[大众点评榜单规则](https://m.dianping.com/an/ranklist/rule/page/fake-traffic?notitlebar=1)强调异常评价与流量处理；本项目沿用登录、点评权限及一人一票机制，不引入独立刷榜入口。

数据库回归覆盖合授、重复教学班去重、最新学期归属、周期隔离。教师汇总基于当前任教关系，不声称是互动发生时的历史教师归属。异步任务的执行速度影响更新时延，运维时应同时运行 API 和任务进程。
